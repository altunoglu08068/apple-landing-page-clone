# 🍏 Apple Store - Homepage Clone

Apple'ın modern ve minimalist web sitesi arayüzünün **HTML5** ve **CSS3** kullanılarak geliştirilen klon çalışması.

> ⚠️ **Yasal Uyarı / Disclaimer:** Bu proje yalnızca eğitim ve pratik amacıyla geliştirilmektedir. Tasarım hakları ve marka materyalleri Apple Inc.'e aittir.

---

## 🚀 Tamamlanan Özellikler

- [x] **Global Navigation Bar (Navbar):**
  - Orijinal Apple SVG ikonları (Logo, Arama, Sepet)
  - `position: sticky` ile üstte sabitlenen yapı
  - `backdrop-filter: blur(20px)` ile buzlu cam (frosted glass) efekti
  - Flexbox (`gap`, `align-items`, `justify-content`) ile responsive hizalama
  - Minimalist hover geçişleri (`transition`)
  - Orijinal Apple hedef bağlantıları (URL)

- [x] **Duyuru & Kampanya Bandı (Promo Ribbon):**
  - Inline SVG (çember içi artı ikonu) ve semantik `<sup>` kullanımı
  - `display: inline-flex` ile ikon-metin dikey hizalaması
  - Apple mavisi etkileşimli link yapısı

---

## 🛠️ Kullanılan Teknolojiler

- **HTML5** (Semantik Etiketler, Inline SVG)
- **CSS3** (Flexbox, Backdrop Filter, CSS Box-Sizing)
